## 修改与重渲染

1. 编辑对应 `.mmd` 源码（[mermaid.live](https://mermaid.live) 在线预览）；
2. 重新渲染：
   ```bash
   # 在 docs/论文图 目录启动静态服务，浏览器打开 render.html 渲染并复制 SVG
   python -m http.server 8091 --directory .
   # 打开 http://127.0.0.1:8091/render.html，控制台执行 copy 后内容覆盖对应 .svg
   ```
   或直接在 [mermaid.live](https://mermaid.live) 粘贴源码导出。
