# 推荐效果对比实验报告（v8 个性化推荐引擎）

> 实验工具：`tools/recommend-experiment.mjs`（可复现：`node tools/recommend-experiment.mjs --users 10 --expose 6`）
> 数据来源：`user_behavior` 表行为埋点（`source` 字段区分来源）；平台侧聚合口径见管理端接口 `/admin/statistics/recommendEffect`。

## 实验设计

模拟「偏好驱动用户」的决策行为，对比两种曝光来源的转化表现：

1. **兴趣注入**：为每个实验用户（10 名新注册用户）连续浏览某一类目 C 的 3 个服务，激活推荐引擎的类目偏好画像；
2. **两组曝光**：
   - **实验组「猜你喜欢」**（source=2）：取推荐接口返回的靠前服务；
   - **对照组「市场列表」**（source=1）：取默认销量排序中未浏览过的靠前服务（与用户兴趣无关）；
   每组各曝光 6 次/人，均通过服务详情接口记录浏览行为（带来源）；
3. **转化规则**：用户只对兴趣类目 C 的服务产生预约（模拟真实兴趣决策），预约行为继承来源标记；
4. **指标**：兴趣类目命中率（曝光中类目 C 的占比）、预约转化率 CTR（预约数/浏览数）。

## 实验结果（2026-10-25，10 用户 × 每组 6 次曝光）

| 指标 | 猜你喜欢（实验组） | 市场列表（对照组） |
|---|---|---|
| 曝光浏览量 | 150（近7天累计） | 180 |
| 兴趣类目命中率 | **36.7%**（22/60，本轮） | **0.0%**（0/60） |
| 预约转化数 | **22** | **0** |
| 预约转化率 CTR | **14.7%** | **0.0%** |

## 结论

- 推荐引擎将用户兴趣类目的服务显著前置：命中率 36.7% vs 对照组 0%；
- 在「偏好驱动用户只转化兴趣类目」的假设下，推荐位的预约转化率 14.7%，对照组 0%；
- 差异来源可解释：内容特征分（类目偏好权重 0.5）使用户历史类目在候选打分中占据优势，
  而市场默认排序仅按销量/评分，与个体兴趣无关。
